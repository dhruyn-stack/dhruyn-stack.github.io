How the eye sees

Light from an object enters the eye through the clear cornea, which bends it the most. The lens then fine-tunes the bend so the light lands sharply on the retina at the back.

Small muscles make the lens fatter for near objects and thinner for far ones. The retina turns light into signals, and the optic nerve carries them to the brain.

Circle it. Copy it.

Hold the title of a card or notebook, then circle any part. Copy it as a picture, or keep it in Clips for any page later.

  1. Hold the title.On a topic card, a notebook or a PDF, hold the title at the top for a moment. The page blurs a little, the edges of the screen glow, and it says “Circle what you want to copy”. You can let go now.

  2. Circle the part you want.Draw a loop around it with your finger or Apple Pencil.

  3. The box snaps to it.It jumps to the whole lines, table cells, tables, pictures and ink inside your circle, and the rest of the page blurs. Drag a corner or an edge to change it. It sticks to the edges on the page.

  4. Tap Copy.A sharp picture of exactly the box goes to the clipboard: “Copied. Paste it anywhere.”

  5. Or tap Add to Clips.The clip waits in Clips (the books button in the toolbar), under the card, notebook or PDF it came from. Search clips finds the words inside, your handwriting too.

  6. Put it on any page.Tap a clip, or drag it onto a notebook page or a topic card. The picture keeps a “From …” link back to where it came from.

Photosynthesis

Photosynthesis

Plants make their own food from light. In the leaf, water and carbon dioxide become glucose, a sugar, and oxygen is given off.

The word equation

carbon dioxide + water light, chlorophyll glucose + oxygen

Where it happens

  • In the leaves, inside tiny parts called chloroplasts
  • Chlorophyll, the green colour, traps the light
  • Water comes up from the roots. Carbon dioxide comes in through small holes called stomata

What speeds it up

Exam trap

Plants respire all the time, day and night. In bright light, photosynthesis is faster, so the leaf gives off more oxygen than it uses.

Lecture in. Card out.

A card is a study page saved as one HTML file (a web page file whose name ends in .html). Lekhin opens it, and you write on it with Apple Pencil. You don't write any code: an AI chat makes the file for you.

  • Your PDFa lecture, slides, book chapter or notes
  • Any AI chatChatGPT, Claude, Gemini or another
  • Lekhinon your iPad
  1. Make the card. Give any AI chat your PDF or lecture and the prompt, then download the .html file it makes.
  2. Put it in Lekhin. In the Library, tap + at the top right, then HTML card, and pick the file.
  3. Write on it. Write over the card with Apple Pencil.

1Make the card

  1. Open any AI chat, on your computer or on your iPad.
  2. Attach your PDF (a lecture, slides, book chapter or notes), or paste your notes into the chat.
  3. Copy the prompt below and send it with your file.
  4. You get back one file whose name ends in .html. Download it. On an iPad, Safari puts it in Files, in the Downloads folder. If the card opens instead, tap Share, then Save to Files.

Using Gemini? Tap Task below the text box before you send, so Gemini can make the file.

Only code on the screen? Ask: “Give me this as a file I can download.” On a computer you can also paste the code into Notepad and save it as “card.html”, with the quote marks. On an iPad, ask again or use a computer.

Want changes? Ask in the same chat, for example “Make the tables bigger”, then download the new file. It comes in as a new card, and your writing stays on the old one, so get the card right before you write on it.

The prompt

Turn the file I sent (a PDF, lecture, slides, book chapter or notes) into one study card: a single HTML file I can download. Make it with your file or code tool and send me the file itself. If you cannot make files, say so, then give me the whole page in one code block, from <!doctype html> to </html>. Name the file after the topic, for example renal-physiology.html. What goes in it: - Use only what is in my file, in the same order. Do not add facts or change any number. If a word or number is hard to read or looks wrong, copy it as written and put "Check this" next to it. - Cover the whole file, to the last page, and do not shorten the later parts. If it is too long for one reply, stop at the end of a section, finish the file properly, and tell me to say "next" for the next part. Make each part a complete card of its own. - Keep the file's language, and keep medical terms and abbreviations exactly as written. Use short, simple sentences and short points, not long paragraphs. - Put the key facts in bold. Use tables for comparisons and simple drawn diagrams for processes, made only from what my file says. - End each section with one or two questions, with the answer hidden until it is tapped. Use <details> and <summary> for this. - After each section, leave an empty box where I can write by hand: an empty <figure> with a thin border, full width and about 150 px tall. How to build it: - Start the file with <!doctype html> on the very first line, then <html>, a <head> with <meta charset="utf-8">, and a <body>. Save it as UTF-8. - Put everything inside this one file: the styles in a <style> tag and diagrams as inline SVG. - Pictures from my file: add them only if you can copy them out with code. Shrink each one to at most 900 px wide and put it in an <img> tag as a data: URI. Never type picture data yourself and never redraw a picture from memory. If you cannot copy a picture, put a box in its place that says "Picture, page 12:" and what it shows. Never leave a broken picture. - Plain HTML and CSS only: no scripts, no links to other files or websites, no fonts or pictures from the web. Use fonts an iPad already has. - Put the topic in <title> (short, real characters, no &-codes) and in one <h1>. Start each section with an <h2>. Use real tags: <p>, <ul>, <table>, <figure>. - The page is always shown 900 px wide, as one tall page that only scrolls down. Make everything fit that width: use box-sizing: border-box, and give img and svg max-width: 100%. Use text about 18 px and nothing under 16 px. Do not use position: fixed or sticky, vh units, sideways scrolling, or boxes that scroll inside the page. Let words wrap inside table cells. - Set every colour as a CSS variable, including the page background on <body> and the colours inside SVG diagrams (there use var(--...) or currentColor, never a fixed colour). Put light colours in :root, and dark colours in both :root[data-theme="dark"] and @media (prefers-color-scheme: dark) { :root:not([data-theme="light"]) { ... } }. Put each picture on a white box so it still shows in dark mode. - Keep the file under 5 MB.

    Questions

    Answered before you could ask.

    Which iPads does it work on?

    Lekhin Notes is made for iPad only. It runs on any iPad with iPadOS 16 or later, and Apple Pencil is the best way to write. On iPads whose Pencil can hover, the laser pointer follows the Pencil before it even touches the screen.

    Do I need an account?

    Not for your notes. The Study Café signs you in on its own without an email or password, so all you choose is a café name.

    Does it work without the internet?

    Yes. Notebooks, cards, the pens, PDFs and handwriting search all work offline. The café and its voice rooms need the internet, and Card Sync needs your home Wi-Fi.

    Can I bring my notes from another app?

    Yes. Export your notebooks from the old app as PDFs, then use Import PDF in Lekhin and keep writing on them.

    How much will it cost, and when can I get it?

    Lekhin Notes will be free as of now, with no in-app purchases. It is coming soon to the App Store, for iPad, and the download link will be on this page on launch day.
